# 幽灵阅读器 · Ghost Reader

一个专为「上班摸鱼看书」设计的 Windows 桌面小说阅读器。
支持 EPUB / TXT，**窗口可整体半透明浮在 IDE 上方**，一键隐身，托盘常驻。

---

## 快速上手

**下载**（约 48 MB，Windows 10 / 11 64 位，无需安装 Python）

👉 [**点此下载最新安装包**](https://github.com/lihanyu-six/ghost-reader/releases/latest)

**方式一：安装版**（推荐）

双击下载的 `GhostReader-Setup-x.y.z.exe` → 下一步 → 完成。
自动创建开始菜单和桌面快捷方式，**无需管理员权限**，卸载走「设置 → 应用」。

**方式二：绿色单文件版**

仓库不含 exe 二进制（体积原因），自行打包即可得到免安装的单文件 exe：

```bash
pip install -r requirements.txt pyinstaller
python -m PyInstaller build.spec --noconfirm
```

产物在 `dist/幽灵阅读器.exe`，拷到任意位置双击就能跑，无需任何运行库。

---

首次启动会弹出欢迎页 → 点「打开一本书」选择你的 EPUB 或 TXT 文件，
或者点「📚 本地书库」「✨ 发现好书」探索。
下次启动会自动恢复上次的书和章节。

## 找书与看书（重点）

### ✨ 发现好书（`Ctrl + D`）
内置 **52 本已完结高分网文**书单，按题材分类：玄幻 / 仙侠 / 历史 / 都市 / 科幻 / 悬疑 / 游戏 / 无限流 / 军事。

每本书带：书名 · 作者 · 题材 · 字数 · **已完结** · 一句话简介 · 推荐理由。

| 操作 | 效果 |
|---|---|
| 单击书 | 在浏览器打开该书的**起点中文网**检索页 |
| 右键 | 「在起点中文网查看」/「在微信读书查看」/「查看简介与评价」 |
| 顶部下拉 | 按题材筛选 |
| 顶部输入框 | 按书名 / 作者搜索 |

书单只是**书目信息**（不含正文），点击后跳转的是**正版平台的公开检索页**，
让想读的人知道去哪儿看、买哪本。软件不内置正文、不代下载。

### 📚 本地书库（`Ctrl + L`）
自动扫描本地文件夹里的所有 `.epub` / `.txt`，列成书架。

- **换文件夹**：指定你的小说目录（默认 `文档\小说`）
- **重新扫描**（`Ctrl + R`）：书放进文件夹后点一下就能看到
- **双击书名**：直接打开阅读

## 核心功能

### 半透明浮窗
- 右侧「设置 → 外观 → 窗口不透明度」滑块，15% ~ 100% 任意调
- 透明度作用于**整个窗口**，包括文字和边框，能透出后面的 IDE 代码
- 快捷键：托盘右键 → 透明度，快速切换 30 / 45 / 60 / 75 / 85 / 95 / 100%

### 文字保护（推荐搭配使用）
透明度调太低，字就会跟着一起变淡、看不清。**「文字保护」滑块专门解决这个问题**：
它把窗口背景做得更透，同时把文字提亮并加描边，做到「背景几乎看不见、字还清楚」。

| 场景 | 窗口不透明度 | 文字保护 |
|---|---|---|
| 正常阅读 | 85% ~ 95% | 0（关闭） |
| 旁边有人路过 | 45% ~ 60% | 60% |
| 极端隐蔽 | 30% ~ 40% | 100% |

实测 40% 不透明度 + 100% 文字保护：背景几乎完全透明，正文依然能顺畅阅读。

### 一键隐身（重点）
| 操作 | 说明 |
|---|---|
| `Ctrl + `` ` | 隐藏 / 恢复窗口（默认热键，可在设置里换） |
| `Esc` | 隐藏窗口 |
| `Ctrl + W` | 隐藏窗口 |
| 点托盘图标 | 显示 / 隐藏 |
| 工具栏 👁 按钮 | 隐藏窗口 |

隐藏后**任务栏不显示任何图标**，只能通过热键或托盘恢复。托盘图标本身也可以右键退出。

可选热键：`Ctrl+`` `、`Ctrl+Shift+`` `、`Ctrl+Alt+`` `、`Ctrl+F12`、`Ctrl+Alt+Q`、`Ctrl+Shift+Space`

### 防截屏模式
设置 → 隐私 → 勾选「防截屏模式」。开启后每 1.2 秒自动扫描进程列表，
发现 OBS / 向日葵 / ToDesk / AnyDesk / TeamViewer / 抖音直播伴侣 / scrcpy 等录屏投屏程序时，
**窗口自动隐藏**，程序关闭后自动恢复。

启动时如果检测到这类程序在跑，托盘会主动提醒你开启。

### 阅读体验
- **滚动模式 / 翻页模式** 两种翻页方式可切换
- **自动滚动**：点工具栏 ⏱ 开启，像提词器一样匀速下滚，到章尾自动跳下一章
- **全文搜索**：`Ctrl + F`，跨 1600+ 章搜索，结果带上下文片段，点击直接跳转并高亮
- **目录**：`Ctrl + B`，带章节名筛选框，1600 章也能秒定位
- **进度记忆**：自动记住读到哪一章，关掉再开接着看
- **章节拼接**：正文区一次渲染 3~4 章，滚到底自动续下一章，不打断阅读
- **迷你模式**：只留正文和一条迷你操作条（上一章 / 下一章 / 还原），高度可自由拉伸压缩到 96px，配合透明度可以贴成屏幕边缘的一条窄缝

### 排版自定义
| 项目 | 范围 |
|---|---|
| 正文字体 | 微软雅黑 / 宋体 / 楷体 / 仿宋 / 黑体 / 等线 / 思源系列 等 |
| 标题字体 | 独立于正文，可单独设置 |
| 字号 | 11 ~ 40 px（`Ctrl + =` / `Ctrl + -` 快速调） |
| 字重 | 细 / 常规 / 中等 / 半粗 / 粗体 / 特粗 / 极粗 |
| 行距 | 110% ~ 300% |
| 字间距 | 80% ~ 300% |

### 主题
内置 7 套配色，一键切换：

| 主题 | 背景 | 适合 |
|---|---|---|
| 暗夜 | `#1E1E20` | 默认，深色 IDE 旁最自然 |
| 纯黑 | `#000000` | 配合高透明度，几乎无痕 |
| 裸透明 | `#101012` | 极暗底色，最隐蔽 |
| 护眼绿 | `#CCE8CF` | 长时间看，眼睛不累 |
| 羊皮纸 | `#F5EDDC` | 纸质书质感 |
| 米白 | `#FAF8F3` | 白天办公室更自然 |
| 蓝灰 | `#2B3440` | 冷色调 |

另有「背景明暗微调」滑块，在选定主题上再 ±40 级微调。

## 窗口操作

| 操作 | 方式 |
|---|---|
| **拖动** | 按住顶部工具栏空白处拖动；迷你模式下按住迷你条拖动 |
| **缩放** | 拖窗口任意边缘 / 四角（8px 命中带），正常模式和迷你模式都可用 |
| **最大化 / 还原** | 双击顶部工具栏空白处 |
| **退出迷你** | 迷你模式下双击迷你条，或点 ⤢ |
| **关闭** | 点 ✕ 或托盘右键「退出」会真正退出；点 👁 或 `Esc` 只是隐藏 |

> 实现说明：内容区铺满窗口，边缘的鼠标事件会被正文控件吃掉，
> 所以缩放逻辑走的是**应用级事件过滤器**（`main_window.GhostReader.eventFilter`），
> 而不是窗口自身的 `mousePressEvent`。命中边缘时光标会变成对应的缩放箭头。
>
> 迷你模式**不再锁死高度**——最小高度降到 96px，仍可自由上下拉伸。

## 源码结构

| 文件 | 职责 |
|---|---|
| `main.py` | 程序入口 |
| `main_window.py` | 主窗口、渲染引擎、章节导航、交互逻辑 |
| `epub_parser.py` | EPUB / TXT 解析引擎 |
| `panels.py` | 目录 / 搜索 / 设置 / 发现好书 / 本地书库 五个侧栏面板 |
| `booklist.py` | 内置精选书单数据（52 本已完结作品） |

| `config.py` | 配置持久化、主题定义 |

| `installer.iss` | Inno Setup 安装包脚本 |

| `ChineseSimplified.isl` | Inno Setup 简体中文语言包（构建用） |

从源码运行：

```bash
.venv\Scripts\python.exe main.py "C:\path\to\book.epub"
```

## 构建与打包

依赖见 `requirements.txt`（运行只需 `PySide6`）。

**从源码打包单文件 exe**：

```bash
.venv\Scripts\python.exe -m PyInstaller build.spec --noconfirm --clean
```

**生成安装包**（需要 [Inno Setup 6](https://jrsoftware.org/isdl.php)，
`ISCC.exe` 换成你的实际安装路径）：

```bash
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

产物在 `installer_out/` 下。

**重新生成图标**（仓库里已有 `app.ico`，通常不需要）：

```bash
.venv\Scripts\python.exe make_icon.py
```

## 使用建议

上班看书最稳的组合：

1. 透明度调到 **40% ~ 60%**，暗夜或裸透明主题，**文字保护拉到 60% ~ 100%**
2. 开 **防截屏模式**（如果公司有监控/录屏软件）
3. 记住 `Ctrl + `` `，一按就消失
4. 用 **自动滚动** 代替翻页，手不用一直动，不容易被注意到
