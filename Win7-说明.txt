==============================================================
  幽灵阅读器 · Windows 7 兼容版  使用说明
==============================================================

本版本专为 Windows 7 SP1 打包，使用 Python 3.8 + PySide2 (Qt 5.15)，
可在 Windows 7 SP1 / 8 / 8.1 / 10 / 11 (64 位) 上运行。


--------------------------------------------------------------
一、如果启动时弹出「缺少 xxx.dll」怎么办？
--------------------------------------------------------------

本程序依赖「Microsoft Visual C++ 2015-2022 运行库 (x64)」。
Windows 7 系统自带的运行库版本较老，缺少下面这类文件：

    api-ms-win-crt-runtime-l1-1-0.dll
    api-ms-win-crt-heap-l1-1-0.dll
    api-ms-win-crt-stdio-l1-1-0.dll
    ...

【解决办法】安装微软官方的 VC++ 运行库，一次解决：

  1. 访问（微软官方短链，会自动跳转到最新版）：
     https://aka.ms/vs/17/release/vc_redist.x64.exe

  2. 下载 vc_redist.x64.exe 并双击安装，按提示重启电脑。

  3. 重新打开「幽灵阅读器」即可。


--------------------------------------------------------------
二、Windows 7 系统前提条件
--------------------------------------------------------------

请确认系统已满足：

  1. 系统为 Windows 7 Service Pack 1 (SP1)
     查看方法：右键「计算机」→「属性」，看「Windows 版本」是否带 Service Pack 1

  2. 已安装 SHA-2 代码签名补丁（否则程序可能提示签名无效）：
     KB4474419（x64）
     下载：https://www.catalog.update.microsoft.com/Search.aspx?q=KB4474419

  3. 已安装通用 C 运行库更新：
     KB2999226（x64）—— 若装不上，装上面的 VC++ 运行库即可替代
     下载：https://www.catalog.update.microsoft.com/Search.aspx?q=KB2999226

  4. 若程序报「api-ms-win-core-path-l1-1-0.dll 缺失」——
     那说明你装到的是「Windows 10/11 版」而不是本 Win7 版。
     请确认安装包文件名为：GhostReader-Setup-Win7-v1.0.1.exe


--------------------------------------------------------------
三、与 Windows 10/11 版有什么区别？
--------------------------------------------------------------

  功能完全一致（半透明、隐身、防截屏、书库、发现好书……全都有）。

  区别只在底层：
    · 10/11 版：Python 3.13 + PySide6 (Qt 6)，体积更小、渲染更现代
    · Win7 版 ：Python 3.8  + PySide2 (Qt 5.15)，兼容老系统

  如果你的电脑是 Windows 10 / 11，两个版本都能装，
  建议装普通版（GhostReader-Setup-v1.0.0.exe），体验更好。


--------------------------------------------------------------
四、常见问题
--------------------------------------------------------------

Q: 双击安装包没反应？
A: 检查是否是 32 位系统。本程序只支持 64 位 Windows。
   查看方法：右键「计算机」→「属性」→「系统类型」。

Q: 安装后桌面图标是白板 / 打不开？
A: 通常是 VC++ 运行库没装，见第一节。

Q: 报错 0xc000007b？
A: 运行库位数不匹配或损坏。卸载已装的 VC++ 运行库，
   重启后再重装 vc_redist.x64.exe。

Q: 卸载后残留配置文件？
A: 配置文件在 C:\Users\<你的用户名>\.ghost_reader\config.json
   卸载不会删除它（保留你的阅读进度），需要彻底清理可手动删除。
